# Social Noir

SocialX

We should create a social media app unlike any other social media platform, well make it no one top social media app.

We are now focusing entirely on the UI/UX of SocialX. Do not focus on the backend at this stage. The priority is to create a highly sophisticated, premium, modern, and polished social-media application.



Overall Visual Identity



SocialX should use a pure black background throughout the entire application.



The app should feel elegant, minimal, immersive, and highly sophisticated.



SocialX should be similar to Instagram in its overall usability, simplicity, navigation, and content presentation, so that the interface feels familiar and intuitive to users. However, SocialX must still have its own unique visual identity and should not simply become an Instagram clone.



Color System



Use only:



- Pure Black — the primary and exclusive background

- White — primary text, icons, and important interface elements

- Red — a carefully controlled accent color



Do not use gray anywhere in the application.



There should be no gray backgrounds, gray cards, gray surfaces, or gray navigation elements.



The interface should primarily be black and white, with red used only where it is genuinely necessary.



Red + Black Treatment



The red + black combination should be part of SocialX's identity, but it must be used carefully.



Do not use too much red.



Red should never dominate the interface or make the app feel like a red-themed application.



Use red only in necessary and meaningful places, such as:



- Notification badges

- The Create (+) button

- Story rings

- Important interactive states where appropriate

- Carefully selected SocialX brand elements



Red should feel special, intentional, deep, and sophisticated.



Avoid bright, light, or overly saturated red throughout the interface.



For elements that use the red + black treatment, use a deep red blended naturally with black rather than a bright red.



Story Rings



Story rings should be an important part of the SocialX visual identity.



The story ring should be noticeably thick and clearly visible, rather than thin.



Use a deep red + black gradient for the story ring.



The red should be darker and richer, with black naturally blended into it.



Do not use a bright/light red ring.



The ring should feel premium, bold, and sophisticated while still remaining clean.



Make the story avatar circles approximately 15–20% larger and tighten the spacing between them so the story tray feels natural and similar in usability to Instagram.



Bottom Navigation



The bottom navigation should have five main buttons:



Home | Discover | + | Clips | Profile



Home



The main social feed.



Discover



Search and exploration.



This section should contain search, recommended users, trending content, and other discovery features.



Because search is already part of Discover, do not place a separate search icon in the top-right of Home.



+



The central Create button.



This should be visually distinctive and can use the red + black treatment, while remaining elegant and minimal.



It should not be an oversized floating button. It should be a normal-sized navigation icon that is consistent with the other bottom navigation icons.



Clips



This is SocialX's short-form video experience.



Throughout the application, refer to this feature as Clips, not Videos.



Profile



The user's personal profile.



Top Bar



Keep the Home top bar extremely clean.



Left:



- SocialX logo



Right:



- Notifications

- Messages



Do not add a search icon to the top bar because search is already available through Discover.



Post Interaction Buttons



The post interaction system should have a familiar Instagram-like layout, while using SocialX's own identity.



Under each post, place the main interaction buttons in this order:



Like · Comment · Repost · Share　　　　　　　　 Save



The Like, Comment, Repost, and Share buttons should be grouped together on the left.



The Save button should be positioned at the far right, separated visually through spacing rather than unnecessary containers.



The interaction area should remain clean and minimal.



Make sure the entire interaction row is always fully visible and does not get cut off or hidden behind the bottom navigation.



Like



Users can like a post by tapping the Like button or by double-tapping the post, with a smooth visual animation.



Comment



The Comment button opens the post's comment section.



Repost



Allows users to repost content to their own SocialX feed.



Share



Allows users to share the post through SocialX and other available sharing options.



Save



The Save button stays at the far right and allows users to save the post for later.



Keep these buttons visually simple, using white icons by default and red only for appropriate active states.



Post Content



Each post should also include:



- Username

- Caption or caption preview below the media

- Timestamp such as “2h ago”

- Proper spacing between all elements



The post should feel clean and naturally structured, similar to the content hierarchy users are familiar with from Instagram.



Background



The background should remain pure black throughout the application.



This includes:



- Home

- Discover

- Clips

- Profile

- Messages

- Settings

- Story viewer

- Post creation

- Comments

- Other major screens



Do not introduce gray backgrounds to separate sections.



Use spacing, typography, white elements, and carefully controlled red accents to create hierarchy instead.



Header Polish



Add a subtle visual separation beneath the top bar/story tray so it feels clearly separated from the feed.



Keep this extremely subtle and maintain the pure-black background.



Do not introduce gray backgrounds.



Scrolling Behavior



The bottom navigation should hide smoothly when the user scrolls down, giving the content more screen space.



When the user scrolls back up, the bottom navigation should smoothly reappear.



The transition should feel natural and polished.



Design Philosophy



SocialX should feel:



- Highly sophisticated

- Premium

- Minimal

- Modern

- Elegant

- Smooth

- Intuitive

- Clean

- Content-focused



Avoid unnecessary decoration, excessive gradients, excessive red, cluttered layouts, or elements that do not serve a clear purpose.



Every UI element should feel intentional.



Important Direction



SocialX should take inspiration from Instagram's simplicity, familiarity, navigation, and content presentation, while creating a distinctive SocialX identity.



The goal is to make SocialX feel immediately familiar to someone who already understands Instagram, while still making it clear that they are using a completely different platform.



The final application should feel like a serious, sophisticated social platform built around a pure-black visual experience, white content, and carefully controlled deep red + black accents.



Do not overuse red. Red should appear only where it is necessary and meaningful.



For now, focus exclusively on making the UI/UX highly polished. Backend functionality will be handled later.
